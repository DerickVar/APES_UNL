# Práctica 2: Comparación de Modelos Determinísticos, Estocásticos, Discretos y Continuos

## 1. Descripción del Proyecto
* **Propósito:** Diferenciar los principales paradigmas de modelado y simulación mediante la construcción de modelos matemáticos y computacionales aplicados al crecimiento poblacional.
* **Problema Resuelto:** Permite evaluar y contrastar cómo se comporta la evolución de un sistema bajo condiciones deterministas exactas, formulaciones discretas por períodos, variabilidad estocástica con ruido gaussiano y aproximaciones continuas mediante el método de integración numérica de Euler.

## 2. Tecnologías Utilizadas
* **Lenguaje:** Python 3.x
* **Librerías principales:**
  * `NumPy`: Manejo de vectores numéricos, cálculo de tasas medias y generación de ruido aleatorio normal.
  * `Matplotlib`: Construcción y exportación de la gráfica comparativa multidimensional.
