# Módulo de Simulación - Práctica 1: Modelo Matemático

## 1. Descripción del Proyecto
* **Propósito:** Construir y simular un modelo matemático en Python para predecir la probabilidad de precipitación (lluvia) a lo largo de un día.
* **Problema Resuelto:** Automatiza el cálculo del índice de calidad atmosférica ($I$) combinando variables meteorológicas discretas y factores térmicos para clasificarlas en estados de alerta (desde "Sin lluvia" hasta "Lluvia").

## 2. Tecnologías Utilizadas
El proyecto fue construido utilizando las siguientes herramientas:
* **Lenguaje:** Python 3.x
* **Librerías principales:** 
  * `NumPy`: Manejo de arreglos numéricos y operaciones matemáticas.
  * `Matplotlib`: Generación de gráficas comparativas de evolución temporal.
